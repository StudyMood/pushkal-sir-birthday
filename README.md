# 🎉 Pushkal Singh | Birthday Tribute & Celebration Website

A creative, interactive digital birthday tribute website celebrating **Mr. Pushkal Singh**, esteemed mentor and management leader at **Digicoders Pvt. Ltd., Lucknow**.

Built with modern web technologies, smooth micro-animations, particle effects, and an interactive celebration experience.

🌐 **Live Demo:** [https://studymood.github.io/pushkal-sir-birthday/](https://studymood.github.io/pushkal-sir-birthday/)

---

## ✨ Features

- 🎆 **Interactive Fireworks & Confetti** — Canvas-driven celebratory fireworks and confetti bursts upon interaction.
- 🎈 **Dynamic Floating Balloons** — Physics-based balloon animations floating in the background.
- 🎂 **Virtual Cake Cutting & Candle Blowing** — Interactive cake cutting experience with celebratory sound effects and animations.
- 🎨 **Theme Switcher** — Dark Luxury Mode, Clean Light Mode, and customizable theme palettes.
- 🎵 **Ambient Background Music** — Built-in celebration BGM player with audio visualizer bars.
- 📸 **Memories Photo Gallery** — Filterable photo gallery with high-resolution lightbox preview.
- 💌 **Wishes & Impact Wall** — Warm appreciation messages, career milestones, and tribute quotes from students and colleagues.
- 📱 **Fully Responsive** — Optimized for desktops, tablets, and smartphones with fluid glassmorphism UI.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic, SEO-optimized markup
- **CSS3** — Custom CSS design tokens, Glassmorphism, animations, responsive layout
- **JavaScript (Vanilla ES6+)** — Interactive modules, fireworks engine, audio controls, celebration events
- **Three.js** — Particle field visualizer
- **Swiper.js** — Touch-enabled slider for memories and milestones
- **Font Awesome 6** — Icons

---

## 🚀 Getting Started

Simply clone this repository and open `index.html` in your favorite browser:

```bash
git clone https://github.com/StudyMood/pushkal-sir-birthday.git
cd pushkal-sir-birthday
```

Or run using VS Code Live Server or Python HTTP server:

```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
